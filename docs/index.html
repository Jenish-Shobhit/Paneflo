Install

  1. Download

    Get the latest zip and unzip it.

  2. Move to Applications

    Open it there. The first time, choose Open Anyway in Privacy & Security.

  3. Grant access

    Allow Accessibility and Input Monitoring. Screen Recording adds window previews.
