Paneflo

Every window.
In its place.

Paneflo is a menu bar app for your Mac that finds, arranges and switches between individual windows: a ⌘Tab that lists windows instead of apps, keyboard tiling, and an organized overview that stays where you put things.

What it does

Three modules that share one list of your windows. Turn on the ones you want.

A window switcher

Hold ⌘ and press Tab to pick a single window, not just an app. The selected window can show a live preview while the picker is open; other cards use cached thumbnails and say so when one is out of date or unavailable.

Tiling inside ⌘Tab

While the picker is open and ⌘ is held, ← or → puts the chosen window in the left or right half, and ↑ fills the display. Release ⌘ and it comes forward, already placed.

An organized Overview

Press ⌃⌥Space for a panel of every window in slots you control. Arrow keys move through the slots, search keeps their places, and Return focuses the window.

Optional: three-finger swipe up

Keyboard tiling anywhere

⌃⌥ with the arrow keys tiles the focused window to a half, ⌃⌥Return fills its display, and ⌃⌥Z undoes the last move.

The menu bar entry

Every view is also in Paneflo's menu bar menu (Switch windows, Arrange windows, Organized overview), so you can try it before turning any shortcut on. Shortcuts and the gesture are opt-in in Settings.

Paneflo's own overview. It is a panel Paneflo draws; it does not change Apple's Mission Control or Spaces. The trackpad gesture is experimental: it uses an unsupported macOS interface and is limited to Apple silicon on a macOS version Paneflo has been checked against, so Settings tells you when it is unavailable.

Install

About a minute, plus the permissions macOS asks for.

  1. Download the zip from the button above and open it. You get Paneflo.app.
  2. Move Paneflo.app to your Applications folder and keep it there: macOS ties Paneflo's permissions to that copy, and updates replace that copy.
  3. Open Paneflo. It isn't notarized by Apple yet, so macOS blocks the first launch once:
    1. In the "Paneflo" Not Opened dialog, click Done.
    2. Open System Settings › Privacy & Security and scroll to Security.
    3. Next to "Paneflo" was blocked, click Open Anyway, then confirm with your password or Touch ID.
  4. Paneflo opens its Settings. Grant the permissions below, then turn on shortcuts (and previews, if you want them).
  5. For the optional gesture: in System Settings › Trackpad › More Gestures, turn off the three-finger Mission Control and App Exposé swipes (or move them to four fingers). Paneflo doesn't change them for you. Then turn on the gesture in Paneflo's Settings.

What it asks for

Accessibility
To find other apps' windows, focus them and move or resize them. Without it Paneflo can't see or place anything. Privacy & Security › Accessibility.
Input Monitoring
To catch ⌘Tab, the tiling shortcuts and the trackpad gesture.Privacy & Security › Input Monitoring.
Screen Recording
Only if you turn on previews, for window thumbnails and the one live preview. Without it the switcher still works, with no pictures. Privacy & Security › Screen & System Audio Recording.

Requirements

  • macOS 26 or later on a Mac with Apple silicon.
  • Free, open source under the MIT license, no account and no analytics.
  • A developer preview: expect rough edges, and check the implementation status for what has and hasn't been verified.

Updates

Paneflo updates itself from GitHub releases, and only when you say so.

  • Choose Check for Updates… in Paneflo's menu bar menu. If a newer version exists you see its release notes and can Install and Relaunch, choose Later, or Skip This Version.
  • Paneflo also checks once a day, quietly, and never while the switcher or Overview is open. Turn that off with Check for Updates Automatically in the same menu; with it off, nothing is requested until you ask.
  • Verified before it's installed. Paneflo checks the download's size and SHA-256, its bundle ID and version, and that its code signature is valid and made with the same certificate as the copy you're running. Anything else is refused.
  • The old copy goes to the Trash, the new one takes its place and opens, and your permissions carry over because the signing certificate is the same. A check sends nothing about you.
  • A copy built locally without the "Paneflo Dev" certificate can't verify a download; install from the releases page instead.
