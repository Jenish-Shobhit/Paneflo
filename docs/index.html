Paneflo

Every window. In its place.

Switch between windows, not apps. Snap them to the edges of the screen, arrange them from the keyboard, and see them all in an Overview that stays in order. One small menu bar app.

Windows, not apps.

Every open window gets its own card, so two browser windows are two choices. The one you pick plays live while you decide.

⌘Tab

Pick one window

Tab steps forward and Shift-Tab steps back. The arrow keys work too. Release ⌘ to focus, or press Escape to cancel.

See it before you go

Only the selected window plays live. The rest show recent snapshots, kept in memory and never saved. Without Screen Recording, cards show app icons.

Act without leaving

With ⌘ still held, close, minimize or hide the selected window, or quit its app. The switcher stays open.

WMHQ

Drag to an edge. It snaps.

Drag a window by its title bar to the edge of the screen. An outline shows where it will land, and it fills that space when you let go. Drag it away and it gets its old size back.

The bottom edge does nothing, so dragging past the Dock never resizes a window. Edges shared between displays let a window cross over. Turn snap areas off in Settings › Tiling.

Or keep your hands on the keys.

Control-Option with an arrow tiles the front window to a half, Return fills the display, and Z restores it. Inside the switcher, ⌘⌥ with an arrow tiles the selected window.

Two halves. One pair.

Two windows side by side on one display become a tile pair, whether Paneflo put them there or you did.

  • Together. Open either window and its partner comes forward too.
  • Or alone. ⌘⌥↩ opens the pair, ⌘A just the one you picked.
  • Swap a half. Tile a third window into one side and it pairs with the other.
  • One undo. Restores every window an arrangement moved, and the pair with them.

Every window, in a place that stays.

The Overview lays out all your windows in slots you control. Search without reshuffling, drag to swap, and keep a place for an app that isn't open yet.

⌃⌥Spaceor swipe up with three fingers

Nothing reshuffles

Slots never move while the Overview is open. Arrow keys move around the grid the way it looks.

Arranged by you

Drag a window onto a free slot to move it, or onto another window to swap. Pinned slots wait for their app.

A Desktop tile

Shows the desktop by hiding other apps, and brings them back when you pick it again. The switcher has one too.

The Overview is Paneflo's own overlay; it doesn't change Mission Control or Spaces. The three-finger swipe is optional and experimental.

Your windows stay on your Mac.

Paneflo sees your windows so it can arrange them. It doesn't send them anywhere.

  • No analyticsNo telemetry, no accounts and no tracking of any kind.
  • Online only for updatesPaneflo talks to GitHub only to check for and download a new release. Turn off the daily check in Settings › Updates.
  • Pictures in memory onlySnapshots are never written to disk, and they're cleared when you lock the screen.

Up and running in a minute.

Paneflo is free and open source under the MIT License.

  1. Download

    Get the latest zip, unzip it, and move Paneflo to your Applications folder.

  2. Choose Open Anyway

    Paneflo isn't notarized yet, so macOS stops the first launch. Click Done, then open System Settings › Privacy & Security and choose Open Anyway next to Paneflo.

  3. Grant access

    Set up Paneflo opens on its own. Click Grant… on each row and switch Paneflo on; the row turns green. Then hold ⌘ and press Tab.

Or skip Open Anyway with one line in Terminal

Instead of steps 1 and 2, open Terminal, paste this and press Return. It downloads the latest release from GitHub, checks its size and checksum and that it's signed with Paneflo's certificate, moves it to Applications and opens it. If any check fails, nothing is installed. Then grant access as in step 3.

$ curl -fsSL https://jenish-shobhit.github.io/Paneflo/install.sh | bash

What Paneflo asks for

Three permissions, and nothing else. If a row says Restart Paneflo to apply, restart it once.

PermissionStatusWhy
AccessibilityRequiredFind, focus, move and resize other apps' windows.
Input MonitoringRequiredHear ⌘Tab, the tiling shortcuts and the trackpad gesture.
Screen RecordingOptionalWindow pictures in the switcher and Overview. Without it, cards show app icons.

To update, choose Check for Updates… from the menu bar icon. Each download is checked against the copy you have before it replaces it, so your permissions carry over.

Questions and answers.

Why does macOS say Paneflo can't be opened?

Paneflo is signed but not notarized yet. Click Done, open System Settings › Privacy & Security, scroll to Security and choose Open Anyway next to Paneflo. You do this once per download; updates installed from the menu bar don't ask again.

To skip this step, install with the one line in Terminal from Install instead.

What does the Terminal command do?

It runs install.sh from this site. The script finds the latest release on GitHub, checks the zip's size and SHA-256 against what GitHub lists, and checks that the app inside is Paneflo, at that version, signed with Paneflo's certificate. Only then does it move any older copy to the Trash and put the new one in Applications. If Paneflo is running, it asks you to quit it from the menu bar icon first.

A file that curl downloads isn't quarantined, so macOS doesn't ask for Open Anyway; the script's checks take the place of that step. Your permissions carry over to the new copy.

Which Macs does it run on?

Macs with Apple silicon running macOS 26 or later. Intel Macs and earlier versions of macOS aren't supported.

Why does it need Accessibility and Input Monitoring?

Accessibility lets Paneflo find, focus, move and resize other apps' windows. Input Monitoring lets it hear ⌘Tab, the tiling shortcuts and the trackpad gesture. Screen Recording is optional and only adds window pictures.

Does it replace Mission Control or Spaces?

No. The Overview is Paneflo's own overlay and leaves Mission Control and Spaces as they are. Windows on other Spaces and full-screen windows aren't always found.

Can I change the shortcuts?

Yes, for tiling: Settings › Tiling › Keyboard Shortcuts has a recorder for each arrangement. If another tool also uses ⌘Tab or ⌃⌥Space, choose Pause Shortcuts in the menu bar to hand those keys back.

The three-finger swipe opens Mission Control.

macOS still owns that swipe. In System Settings › Trackpad › More Gestures, turn off the three-finger Mission Control and App Exposé swipes, or move them to four fingers. Then turn the gesture on in Settings › Overview & Gesture. It works with the built-in trackpad only.

How do I uninstall it?

Quit Paneflo from the menu bar and move it to the Trash. To remove its settings too, run defaults delete dev.paneflo.Paneflo in Terminal.

Something isn't working.

The troubleshooting guide covers permissions, shortcuts, previews and updates. If it doesn't help, open an issue.
