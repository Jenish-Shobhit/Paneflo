# Keyboard shortcuts

Everything here is also listed, searchable, in **Settings › Shortcuts & Help**. ⌘ Command, ⌥ Option, ⌃ Control, ⇧ Shift.

## Switcher

| Keys | Action |
| --- | --- |
| ⌘Tab | Open the switcher; each press steps forward |
| ⌘⇧Tab | Step backward |
| ← → (⌘ held) | Step; ↑ ↓ move by row |
| Release ⌘ | Focus the selected window |
| Esc | Cancel |

## Window actions (⌘ held in the switcher)

| Keys | Action |
| --- | --- |
| ⌘W | Close the selected window |
| ⌘M | Minimize it |
| ⌘H | Hide its app |
| ⌘Q | Quit its app (never Finder) |
| ⌘A | Open the selection without its tile partner |

## Tiling

| Keys | Action |
| --- | --- |
| ⌃⌥← / ⌃⌥→ | Frontmost window to the left / right half |
| ⌃⌥↑ / ⌃⌥↓ | Frontmost window to the top / bottom half |
| ⌃⌥Return | Fill the display |
| ⌃⌥Z | Undo the last arrangement |
| ⌘⌥← / ⌘⌥→ | Switcher or Overview: selected window to the left / right half (repeat moves to the next display) |
| ⌘⌥↑ | Fill the display |
| ⌘⌥↓ | Undo for the selected window |

Without keys: drag a window by its title bar to the top edge to fill the display, a side edge for that half, or a corner for a quarter (Settings › Tiling).

## Tile pairs

| Keys | Action |
| --- | --- |
| ⌘⌥Return | Open the selection with its partner (switcher or Overview) |
| ⌘A (switcher) / ⌥Return (Overview) | Open the selection alone |
| ⌘⌥← then ⌘⌥→ on another window | Snap assist: place it beside the first and pair them |

## Overview

| Keys | Action |
| --- | --- |
| ⌃⌥Space | Open the Overview |
| Arrows | Move spatially |
| Type | Search (slots stay in place) |
| Return | Focus the selection (with its partner) |
| ⌥Return | Focus without the partner |
| Esc, or click the background | Close |
| Drag | Move to a free slot, or swap with another window |
| Right-click | Open Pair, Open Alone, Unpair; Remove on a free slot |

## Trackpad (optional)

| Gesture | Action |
| --- | --- |
| Three fingers up | Open the Overview |
| Three fingers down | Close the Overview |

## General

| Keys | Action |
| --- | --- |
| ⌘, | Settings (from the menu bar item) |
| Menu › Pause Shortcuts | Release ⌘Tab and the other keys to macOS or another tool |

If another tool also hooks ⌘Tab or ⌃⌥Space, precedence is not guaranteed; pause one of them. See [troubleshooting](troubleshooting.md#a-shortcut-does-nothing).
